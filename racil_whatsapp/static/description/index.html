طريقة الاستخدام

  1. ثبّت الإضافة (تعتمد على «المناقشة» فقط).
  2. افتح أي فاتورة أو عرض سعر أو جهة اتصال واضغط زر واتساب (أو Shift+W).
  3. راجع الرقم والرسالة — اختر فصحى أو خليجي أو إنجليزي — ثم اضغط فتح واتساب وأرسل.
  4. من الإعدادات ← زر واتساب: الدولة الافتراضية، لغة الرسائل، نوع الرابط، والمستندات المفعّلة.
